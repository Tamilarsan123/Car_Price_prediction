# 🚗 Car Price Prediction Model

This project is a Machine Learning model that predicts the price of a car based on various features such as company, year, fuel type, and more.

---

## 📌 Project Overview

The goal of this project is to build a predictive model that estimates car prices using historical data. This can help buyers and sellers make better pricing decisions.

---

## 🛠️ Technologies Used

- Python 🐍
- Pandas 📊
- NumPy 🔢
- Matplotlib 📈
- Seaborn 🎨
- Scikit-learn 🤖
- Jupyter Notebook 📓

## 📂 Dataset

The dataset contains information about:

- Company
- Year

- Fuel Type
- Kilometers Driven
